# Archive: MobileNetV2 pipeline (superseded)

Results, histories, reports and confusion matrices from the first version of the experiments,
which used MobileNetV2 as the main backbone (experiments E2/E3). They are kept for
transparency only and **do not correspond to the numbers in the paper**, which uses
EfficientNetB0 as the main backbone. The notebooks that produced them are in
`notebooks/archive_mobilenetv2/`.
